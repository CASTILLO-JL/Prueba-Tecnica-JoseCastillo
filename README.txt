HERRAMIENTAS, LENGUAJES Y FRAMEWORKS UTILIZADOS:
1. Pycharm
2. Selenium
3. Python
4. Pytest


INSTALACIONES NECESARIAS:
1. Instalar python v3.12.10 (PUEDE SER DE MANERA GLOBAL)
2. Instalar IDE PYCHARM v2026.1.4


EJECUCION:
1. Ya que se utilizó entornos virtuales, se debe acceder y encender la máquina virtual desde la consola o CLI de la siguiente manera:
2. Ubicarse en la carpeta MV1, escribir cd Scripts y presionar enter.
3. Dentro de la carpeta Scripts, escribir ./activate y presionar enter.(COMANDO PARA ENCENDER LA MAQUINA VIRTUAL, NORMALMENTE SE MUESTRA UN INDICADOR EN LA CONSOLA)
4. escribir el comando py.test Test_Base_Page.py -s -v (ESTE COMANDO EJECUTARÁ LA PRUEBA AUTOMATIZADA, TIENE QUE SER FUERA DE LA CARPETA SCRIPTS, PERO DENTRO DE LA CARPETA MODULS YA QUE AHI SE ENCUENTRA EL ARCHIVO QUE SERA EJECUTADO)

OBS: (DE SER NECESARIO, O SEA, EN CASO QUE ALGO FALLE AL MOMENTO DE REALIZAR LA EJECUCIÓN)
En el interprete de pycharm, en configuracion se debe instalar los siguientes paquetes:
1. selenium v4.46.0
2. pytest v9.1.1
3. virtualenv v21.7.5
4. python v3.12.10
